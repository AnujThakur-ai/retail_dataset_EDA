# Retail Dataset Exploratory Analysis

A hands-on exploratory data analysis project using retail transaction data and supporting country lookup tables.

## Contents

- `Untitled.ipynb` — notebook-based exploration.
- `retail_data.py` — an in-progress analysis script.
- `data.csv` and `data.csv.zip` — transaction data in extracted and compressed form.
- `country_codes.csv` and `Country_Names_and_Codes.csv` — country reference files.

## Run

Open the notebook in Jupyter or VS Code. The analysis expects the CSV files in the working directory and reads the transaction data using Latin-1 encoding.

The script currently includes IPython notebook magic, so run it from a notebook environment or adapt it before using it as a standard Python script. The analysis is exploratory and may be incomplete.
